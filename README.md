## Feedback welcome

Whos is shaped by the people who use it. Found a bug, want a feature or integration, or have an idea, big or small? [Open an issue](https://github.com/juannavalonribas/whos-support/issues/new/choose) and pick a template. It only takes a minute, and every report is read.

The application source code is maintained in a separate private repository.
