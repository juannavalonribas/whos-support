# Whos support and downloads

Official support repository for Whos. Report bugs, request features, suggest integrations, and share feedback through [Issues](https://github.com/juannavalonribas/whos-support/issues).

Installers and release notes will be published in [Releases](https://github.com/juannavalonribas/whos-support/releases).

This repository contains support information and release files. The application source code is maintained in a separate private repository.
