Official support repository for Whos. Report bugs, request features, suggest integrations, and share feedback through [Issues](https://github.com/juannavalonribas/whos-support/issues).

## Feedback welcome

Whos is shaped by the people who use it. Found a bug, missing something, or have an idea, big or small? [Open an issue](https://github.com/juannavalonribas/whos-support/issues/new/choose) and pick a template. It only takes a minute, and every report is read.
